# Farah Naaz — A Birthday Full of Love
Soft Pink & Rose Gold · Asad ka birthday surprise · Alisha ka special gift.

## Website open karna
1. ZIP ko Windows mein right-click → Extract All karein.
2. Extracted **Farah-Naaz-Birthday-Website** folder mein `index.html` open karein.
3. Open Your Surprise → **28 October 2006** choose karein → Check My Birthday.
4. Success ke baad Unlock My Birthday Magic dabayein.
5. Countdown se foran Open Birthday Surprise kar sakte hain. Target **28 October 2026**, visitor ki local midnight hai; birthday aa chuki ho to seedha celebration khulega.

## Aapki audio ab included hai
- Bheji hui WhatsApp audio `assets/birthday-music.mp3` mein included hai.
- Yeh default music hai. Header ka **Music** button click karke chalayein.
- Play/Pause, Mute/Unmute aur Volume isi audio par kaam karte hain.
- Website load hone par sound automatically nahi bajti.
- My music se doosri local audio select kar sakte hain; Use original tune se synthesized tune par ja sakte hain. Refresh par included WhatsApp audio default ho jati hai.
- Replay audio ko pause karke shuru par reset karta hai.
- Baad mein music badalni ho to apni file isi naam `assets/birthday-music.mp3` se replace karein. Full assets folder hosting par upload karna zaroori hai.

## Farah Naaz ki photo permanently included hai
- Aapki supplied photo **assets/farah-naaz.jpeg** mein website ke saath included hai.
- site-content.js already isi picture par set hai. Aapko photo select ya photo-kit download nahi karni.
- Poora updated website folder GitHub par upload karein; image bhi sab visitors ko nazar aaye gi.
- Frame photo ke natural proportions follow karta hai; full picture nazar aati hai, koi face crop/stretch nahi.
- Original image bytes preserve kiye gaye hain; face ya image content mein editing nahi hui.

- Baad mein photo change karni ho to Add / change photo aur publishing kit available hain.

- One portrait with local picker, browser persistence and publishing kit.
- Included personal audio with play/pause, mute and volume.

## Free GitHub Pages hosting
1. GitHub par sign in → + → New repository.
2. Name **farah-naaz-birthday**, Public choose karein → Create repository.
3. Add file → Upload files.
4. Extracted website folder ke ANDAR ki saari files aur **assets** folder upload karein. Outer folder nahi: index.html repository root mein hona chahiye.
5. Commit changes karein.
6. Settings → Pages → Source: Deploy from a branch.
7. Branch **main**, folder **/(root)** → Save.
8. Actions tab mein deployment complete hone dein.
9. Settings → Pages ka actual published URL open karein.
10. Music, portrait aur buttons live test karein. WhatsApp share ab current public URL use karega.

Abhi GitHub par deployment nahi ki gayi. Local file/localhost par WhatsApp button deployment reminder deta hai. Date gate playful interaction hai, secure authentication nahi; date frontend code mein nazar aa sakti hai.

## Troubleshooting
- Design/buttons missing: ZIP extract karein; saari JS/CSS files saath rakhein.
- Audio missing: assets folder upload hua ho; Music click karein; Mute/Volume/device sound check karein.
- Photo sirf mere laptop par: local selection public upload nahi hoti. Photo publishing kit extract karke dono files GitHub root mein upload karein.
- Photo saving unavailable: browser storage blocked ya image bari ho sakti hai. Publishing kit phir bhi download kar sakte hain.
- Broken published portrait: photo aur site-content.js same root folder mein hon, image filename/case match kare.
- Photo format unsupported: JPG ya PNG use karein. HEIC ko pehle JPG mein export karein.
- Font different offline: installed font fallback use hota hai; internet par Google Fonts load hoti hain.
- 404: index.html root mein ho; Pages main/(root) par ho; Actions completion ka wait karein.
- Old content: Ctrl+F5; photo local override ho to Reset photo.
- Copy blocked: manual copy field use karein.
